# ZextaPay - Payment Monitor for WooCommerce

Monitor your WooCommerce payment gateways in real-time. See failed transactions, track revenue at risk and keep your store healthy.

## Free Features

- Live dashboard with successful and failed transactions
- Revenue at risk tracking
- Human-readable error descriptions
- 7-day transaction history

## Premium Features

Premium versions are available via Freemius:

- **Starter** — Real-time Slack and Telegram alerts, 30-day history
- **Growth** — Automatic gateway failover, auto-restore, 90-day history

## Installation

1. Upload the `zextapay-payment-monitor` folder to `/wp-content/plugins/`
2. Activate through the Plugins menu in WordPress
3. Go to ZextaPay in your admin menu

## Development

Built with React and PHP.

To rebuild the dashboard:

```bash
npm install
npm run build
```
